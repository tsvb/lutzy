# Curate a repository-local LUT library

## Why

The current local library contains a small manually imported set, while the user has several much larger LUT sources spread across other working directories. Copying those folders verbatim would preserve duplicates, archives, unsupported 1D LUTs, generated release candidates, and ambiguous provenance. It would also leave Brand, Tags, and Description trapped in the local app catalog rather than travelling with a corpus that may later be managed in Git.

The application also has no durable Description field. LUT Manager can edit Name, Brand / Source, Tags, Collections, physical folder, and Starred state, but it cannot show or maintain the provenance notes required for this curated corpus. LUT Library detail therefore cannot explain whether a look was generated by Codex, generated by Claude, or imported from an identified GitHub project.

## What changes

- Add a repository-local `LUTLibrary` corpus with an active 3D library grouped as `<Brand>/<Source>/…`.
- Preserve source-relative provenance while deduplicating exact content and keeping unsupported transforms outside the active scan root.
- Add a versioned `.lutzy-library.json` sidecar manifest keyed by SHA-256 rather than mutable filenames.
- Seed Brand, precise Input Profile, descriptive Tags, and Description when a manifest-backed LUT first becomes a catalog record.
- Keep Brand, Input Profile, and Tags independent: a Fujifilm-look LUT may still require Panasonic V-Log input, while Panasonic STD adapters remain explicitly STD.
- Repair legacy `Unknown` Brands once from unambiguous folder/name evidence without overriding later user edits.
- Preserve user edits after the initial seed; rescanning SHALL NOT reset curated or user-authored catalog metadata.
- Add a durable Description field to `LUTRecord`, a Description table column and Inspector editor in LUT Manager, and Description content in LUT Library detail.
- Copy a valid sidecar manifest when importing its containing folder so metadata follows the LUTs into the managed library.
- Record source attribution and license/reference status without modifying third-party `.cube` bytes.

## Scope

Initial curation covers the user-supplied Film-Luts, Codex-generated LUT project, Claude-generated LUT project, V-Log-Alchemy GitHub project, and Documents LUT collection. Missing references for the Documents collection remain explicitly pending rather than being guessed.
